# Budget-and-Expense-Analyzer-using-SQL
An interactive Streamlit dashboard that helps users upload transaction data, automatically save it into a SQLite database, analyze spending patterns with SQL queries, view financial charts, and export a professional Excel report.

## Project Overview

This project was built to demonstrate practical finance, data analysis, SQL, and reporting skills. Users can upload a CSV file of transactions, and the app automatically cleans the data, stores it in a SQLite database, and generates dashboard insights.

## Features

* Upload transaction CSV files

* Automatically clean and save transactions into SQLite

* View financial summary metrics

* Analyze income, expenses, net savings, and savings rate

* Review SQL queries directly inside the app

* Analyze spending by category

* View monthly income vs expenses trends

* View daily expense trends

* Export a professional Excel report with multiple sheets and charts

## Tools Used

* Python

* Streamlit

* Pandas

* SQLite

* SQL

* Plotly

## Dashboard Sections

### Upload

Users can upload a CSV file containing transaction data. The app automatically cleans the file and saves the records into a SQLite database.

### Dashboard

Shows high-level financial metrics, including total income, total expenses, net savings, and savings rate.

### SQL Analysis

Displays SQL queries and results for income, expenses, and top spending activity.

### Categories

Shows spending grouped by category with a visual chart.

### Trends

Shows monthly income vs expenses, monthly net savings, and daily expense trends.

### Export

Generates a professional Excel report with formatted sheets, summary metrics, and native Excel charts.
